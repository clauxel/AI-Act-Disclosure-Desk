# Workflow

AI Act Disclosure Desk maintains AI feature inventory, user touchpoints, disclosure text versions, reviewer signoff, and Article 50 evidence exports.

## Repeatable Flow

1. Add AI features, user touchpoints, regions, and disclosure text.
2. Map disclosure obligations and compare copy versions.
3. Route gaps to product, legal, or policy reviewers.
4. Export an Article 50 evidence pack and history.

## Output Mindset

The useful artifact is not a marketing claim. It is evidence that a reviewer can inspect, export, and compare later.
