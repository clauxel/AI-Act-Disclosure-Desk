# AI Act Disclosure Desk

Keep every AI disclosure notice traceable before regulators ask.

AI Act Disclosure Desk maintains AI feature inventory, user touchpoints, disclosure text versions, reviewer signoff, and Article 50 evidence exports.

This is a public documentation project for AI Act Disclosure Desk. The structure is modeled after the public documentation pattern used by [MiroFish](https://github.com/clauxel/MiroFish): a short front door, a clear reading order, practical guides, reference pages, and public-safe architecture notes.
